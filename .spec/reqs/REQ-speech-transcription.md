# 本地 ASR、GAP 与重识别

ASR 仅在设备上运行，音频/PCM 不上传；X-ASR 480ms INT8 单模型候选，权重不进 APK，版本化清单、签名验证、SHA-256、防回滚、更新、回滚与租约/pending-delete；区分 Partial/Final，Final 为不可变 L0 并绑定 UTC/单调/实际音频时间与有序块引用；最旧未处理 PCM 排队时延超过 15000ms 时插入居中 `...` 的不可变 GAP 并跳到最新音频，只丢 ASR 识别副本不删证据音频；所有文本段与 GAP 可用会话固定同一模型离线重识别，成功新增版本且不覆盖原证据。

## 成功标准

- 模型决策前冻结精确工件/revision/hash 与预注册准确率、速度、资源预算。
- 应用打开立即异步预加载已选模型，准备/就绪/失败及重建原因在设置可查；模型导入、刷新、选择与其他真实管理操作集中设置。顶部唯一录音控制在模型未就绪时不得假启动实时转写，仅录音须显式确认；必要错误/确认位于中间区域外，中间区域始终仅 ASR 结果，无结果留空。
- 同模型工件/安装版本/配置在进程内复用已加载权重，开始、新会话、暂停和继续不卸载；会话及重识别 stream、缓存、端点、时间与事件世代隔离。显式切换、资源回收、运行时失效或进程重启可重建，须可观察，不宣称永不重载，也不得破坏会话固定模型与租约。
- 高一档模型必须完成候选筛选→精确工件/revision/hash 固定→同冻结协议双设备实际对比→依据实测决定；型号待定，保留原 X-ASR 固定工件及溯源，不放宽准确率、持续 `RTF < 1` 与 p95 落后 ≤15 秒门槛，不预先宣称更好。
- 设置仅包含真实可操作/可调整项目及必要值、状态和错误，不包含需求说明、外观动效介绍、当前模式或不可操作占位。
- 15 秒跳读按单调时钟触发，GAP 保留跳过区间与 ASR_OVERLOAD 原因。
- 以 `openspec/changes/add-live-semantic-transcript/specs/speech-transcription/spec.md` 的 Requirement 与 Scenario 为准，不维护易失条目计数。用户已确认真机转写可用，仅证明该路径可用；不代表预加载/复用、高一档对比、双设备质量性能或发布全面验收，任务原有未验收状态保持。
