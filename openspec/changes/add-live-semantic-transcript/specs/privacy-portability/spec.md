# Privacy Portability

## ADDED Requirements

### Requirement: 明示权限与文字离机

系统 SHALL 在录音前请求必要权限，并在首次 BYOK 请求前说明将发送的数据类型和目标主机；系统 MUST NOT 将音频离机作为本地 ASR 或 LLM 的隐含行为。

#### Scenario: 首次配置 BYOK

- **WHEN** 用户首次启用兼容端点
- **THEN** 界面显示稳定文字、必要上下文和生成任务会发往的主机
- **AND** 用户确认前不发送生成请求

#### Scenario: 撤回权限或禁用端点

- **WHEN** 用户撤回麦克风权限或关闭 BYOK
- **THEN** 对应新活动停止，已有本地数据仍按保留策略保存
- **AND** 系统提供清晰的恢复设置入口

### Requirement: API Key 本机保护

系统 SHALL 使用 Android Keystore 支持的安全存储保护 BYOK API Key，并 MUST 防止其进入明文数据库、日志、分析事件和普通导出。

#### Scenario: 保存与读取密钥

- **WHEN** 用户保存或应用读取 API Key
- **THEN** 密钥只通过受保护存储和内存中的必要请求路径使用
- **AND** UI 默认掩码显示，日志仅记录脱敏主机与错误类别

#### Scenario: 导出或诊断

- **WHEN** 用户导出会话或诊断信息
- **THEN** 产物不包含 API Key、Authorization 头或完整敏感请求正文

### Requirement: 长期保留与禁止自动删除

系统 SHALL 默认长期保留录音分块、转写和版本，直到用户明确删除，MUST NOT 为继续新录音而自动删除最早音频。

#### Scenario: 达到容量预警

- **WHEN** 可用空间低于预警阈值
- **THEN** 系统显示容量与预计可录时长并建议导出或手动清理
- **AND** 所有既有会话保持原样

#### Scenario: 达到硬存储下限

- **WHEN** 可用空间不足以完成当前块封存、下一块占位/初始化或必要数据库提交
- **THEN** 系统先停止接收切点后的新 PCM 并保持 `BLOCKED`，不创建下一块占位，再排空切点前已接受数据并尽力封存当前块
- **AND** 音频封存与数据库冲刷成功后才显示低存储暂停；失败时显示保存异常和实际边界，不把失败伪装成用户暂停
- **AND** 系统不自动删除旧音频；空间恢复后等待用户明确继续，并从新的完整占位协议开始

### Requirement: 音频分块合并导出

系统 SHALL 在用户导出一个会话时按 `chunkSeq` 合并源音频，并 SHALL 保持源分块不变；同编码兼容时 SHALL 优先转封装而不是重复编码。

#### Scenario: 导出完整会话

- **WHEN** 用户选择音频导出且空间与源块校验通过
- **THEN** 系统按实际录音顺序生成一个可播放音频文件，不补入暂停静音
- **AND** 导出参数、时长校验和源块清单可检查

#### Scenario: 导出中断或失败

- **WHEN** 合并过程中取消、空间不足或某块损坏
- **THEN** 系统不删除源块，不将半成品标记为成功
- **AND** 系统清理可安全清理的临时文件并允许重试

### Requirement: 文本与证据导出

系统 SHALL 支持导出原始 ASR、当前校订、要点、摘要、引用和音频时间映射，并 SHALL 明确各层来源。

#### Scenario: 导出可读文档

- **WHEN** 用户导出 Markdown
- **THEN** 文档包含会话标题、当前有效层级、GAP/重识别来源和必要时间信息
- **AND** AI、用户校订或重识别不被标记为原始 ASR；居中 `...` 标明为 ASR 过载缺口而非说话内容

#### Scenario: 导出结构化备份

- **WHEN** 用户导出 JSON
- **THEN** 会话、音频块索引、ASR/GAP 与重识别版本、父版本、有序来源、`sourceSetHash`、引用、三时间域映射和模型元数据保持稳定标识
- **AND** GAP 保留跳过区间与 `ASR_OVERLOAD` 原因，不用空字符串或伪造 L1 代替
- **AND** 导出不包含 BYOK 密钥或受保护系统路径凭据

### Requirement: 用户明确删除

系统 SHALL 仅在用户明确确认后删除会话及其本地关联数据，并 SHALL 处理正在进行的任务和文件引用。

#### Scenario: 删除历史会话

- **WHEN** 用户确认删除一个未活动会话
- **THEN** 系统取消相关可取消任务，删除文字、GAP、重识别版本、音频块、引用和导出索引
- **AND** 不影响其他会话或共享模型安装；仍被其他租约使用的模型工件不得删除

#### Scenario: 删除活动会话

- **WHEN** 用户尝试删除正在录音的会话
- **THEN** 系统要求先通过明确流程结束或暂停并封存
- **AND** 不在采集线程仍写入时直接移除文件

### Requirement: 脱敏可观测性

系统 SHALL 让诊断信息足以定位错误，同时 MUST 默认排除完整转写、音频内容和秘密。

#### Scenario: 记录 BYOK 失败

- **WHEN** 端点返回错误或超时
- **THEN** 日志记录主机脱敏标识、状态类别、重试次数和任务类型
- **AND** 不记录 API Key、完整提示词或响应中的用户文字
