# Proposal

## Why

长时间录音转写会累积大量重复、口语化和识别不稳定的文字。用户既要紧跟最新内容，也要快速理解旧内容，还需要核对识别或模型是否改错。单纯实时字幕不能降低阅读负担，单纯摘要又会切断证据。

本项目将录音可靠性、实时本地识别、可追溯校订和渐进折叠组合为一条完整链路，并通过可打断动画与明确滚动规则，避免持续追加和自动折叠抢夺用户的阅读位置。

## What Changes

- 新增 Flutter 三页应用外壳：录音列表、录音、设置；页面状态与录音生命周期解耦。
- 新增 Android 麦克风前台服务，从单次 PCM 采集分发本地 ASR、振幅采样和 AAC 编码，不引入远端 ASR；采集、ASR、编码与持久化队列均有界。
- 新增目标 192kbps 的 AAC-LC/M4A 长期证据音频，默认 60 秒自动分块；新块先原子持久化占位再初始化编码器，支持按段回听和导出时合并。
- 新增外置 X-ASR 480ms 单模型管线，模型独立于 APK 下载、校验、安装、租约、更新与回滚；精确工件、INT8 来源和哈希须在模型决策前固定。
- 新增 ASR 过载降级：待识别音频落后超过 15 秒时插入显式不可变 GAP，以居中 `...` 展示并跳到最新音频；所有文本段和 GAP 可用会话固定模型离线重识别，成功新增版本而不覆盖原证据。
- 新增顶部右进左出的实时振幅条和大红录音按钮，支持暂停/继续，以及带惯性但以实际位移为准的左滑结束新建。
- 新增实时转写、校订全文、段落要点、会话摘要和 L0 证据视图；原始 ASR/GAP 永不覆盖，多源产物使用有序来源和 `sourceSetHash` 校验。
- 新增即时预处理与独立自动折叠计时，支持单击逐级展开、双击最短档、长按编辑/回听/复制/重识别。
- 新增跟随底部/自由阅读状态机、方向性展开折叠、会话内 `ReaderContext`、阅读锚点和可解释、可打断的弹簧动画。
- 新增手机直连 OpenAI-compatible BYOK，默认 HTTPS 且跨域重定向不转发凭据；只有稳定文字用于校订、要点、摘要和标题；密钥仅保存在本机安全存储。
- 新增录音列表自动标题及“首次实际可见时播放一次”的持久化标题替换动画；未展示的最新有效标题继承唯一首展资格。
- 新增长时恢复、低存储保护、背压、幂等、引用与人工语义验收、预注册质量门槛和可观测性。

## Capabilities

### New Capabilities

- `audio-capture`: 显式后台录音、暂停继续、左滑结束新建、有界 PCM 分发、原子块占位与封存、192kbps AAC 分块及振幅采样。
- `speech-transcription`: 外置本地 X-ASR 模型、流式临时/最终结果、15 秒 GAP 跳读、逐段离线重识别、稳定段落与三时间域。
- `live-transcript`: 三页导航、实时文字与 GAP、振幅条、滚动模式、方向性动画、长按操作与 `ReaderContext`。
- `semantic-zoom`: L0–L3 内容模型、不可变证据、自动折叠、手动展开锁定、编辑版本、引用和原文回查。
- `processing-orchestration`: 即时预处理、BYOK HTTPS 适配、有序多源校验、任务优先级、幂等、缓存、过期重建与标题生成。
- `privacy-portability`: 权限与明示离机、密钥保护、长期保留、低存储保护、复制和音频/文本导出。
- `reliability-observability`: 长时运行、恢复、降级、诊断、质量指标与性能预算。

### Modified Capabilities

无；这是新项目的首个行为变更。

## Impact

- **新应用**：Flutter UI、Kotlin 前台服务与音频管线、sherpa-onnx 本地推理、drift 数据库、BYOK 适配器。
- **外部依赖**：Flutter/Android 官方或成熟包、MediaCodec/MediaMuxer、Media3 Transformer、外部 ASR 模型文件、用户自备兼容 LLM 端点。
- **数据**：会话、带三种时间域的音频块状态、ASR/GAP/重识别版本、语义节点、三级产物、有序来源与 `sourceSetHash`、用户编辑、任务、模型租约和标题展示状态。
- **网络与安全**：仅 LLM 文字与模型下载联网；默认 HTTPS，跨域重定向不转发凭据；API Key 不进日志、数据库明文或导出；录音与文本访问需权限和授权。
- **验证**：两台参考设备的 30 分钟可行性尖刺与两小时发布长测分离；分块完整性、杀进程/低存储/断网、手势与滚动自动化、ASR/GAP/重识别与生成质量评测、OpenSpec 固定版本严格校验。
- **许可**：可借鉴 TextFold 的层级和展开思想；若复用代码须遵循 Apache-2.0 与 NOTICE，不复用则不受其代码许可约束。

## Out of Scope

- 远端 ASR、音频上传、自建中继、第二模型识别、自动补转写；用户主动触发的同模型逐段重识别不属于自动补转写。
- 全天候隐蔽常驻、自动无感重启录音、通话录音。
- 说话人分离、声纹、翻译、问答、多设备协作与云同步。
