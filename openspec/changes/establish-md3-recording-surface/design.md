# Design

## Context

本变更在已有真实录音采集切片上落实设计系统与录制界面。真实会话由 `app_shell/lib/ui/recording/recording_controller.dart` 的 RecordingController 编排，原生快照确认业务状态；UI 动画不拥有麦克风、音频块或会话生命周期。现有 `app_shell/lib/ui/motion/echo_motion.dart` 已有统一时长、曲线、弹簧和减少动态效果入口，应沿用和扩展这一约定。

`openspec/changes/add-live-semantic-transcript/` 尚未归档，主规格目录尚未建立对应能力。该变更的采集、阅读与页面保留规则是本变更的关联来源。本变更只新增可独立验收的设计与录制界面约束，两个 delta spec 使用 `ADDED Requirements`；将来归档时先协调同名能力与重复需求，不假设空主规格已有可供修改的 Requirement。

## Goals / Non-Goals

### Goals

- 全项目采用 Material Design 3，颜色、排版、形状、状态层与组件主题有同一来源。
- 用 Material 语义组件实现参考图布局，保留最亮前景波形及两端 alpha 渐隐。
- 让操作反馈立即开始，所有视觉变化连续、平滑、可打断，取消也有完整回弹。
- 交付保留状态的最小真实三页导航，并清楚区分已接入能力与尚未接入能力。
- 在视觉改造中保持真实录音、安全封存、证据、业务手势及可访问性契约。

### Non-Goals

- 本轮不完成历史服务、完整设置、ASR 接线或完整语义阅读。
- 不改变已授权的录音安全行为，不创建模拟数据，也不以动画完成时刻替代原生确认。
- 不以主题覆盖声明所有现有页面已经完成组件迁移和交互验收。

## Decisions

### 1. Material 3 与语义配色生成是唯一颜色来源

应用使用 Material 3 ThemeData 与 ColorScheme 配色引擎，并由统一主题层提供 Typography、组件主题和状态层。ColorScheme.fromSeed 等 Material 语义方案生成方式符合本次要求；系统壁纸配色若无既有接入，不属于本次必须项，不要求安装 dynamic_color。具体方式复用项目现有工具，不从参考图采样，不新增硬编码品牌调色板，不为本轮安装依赖。

参考图的深蓝灰 surface 与橙红控制只表达暗色背景、容器层次和突出主要操作的视觉关系。surface 使用 ColorScheme 的 surface/容器角色，文字使用对应 onSurface 角色，主控制使用适合主要操作的 primary 与 onPrimary，错误使用 error 与 onError。Material 配色引擎生成的主题可以改变色相；不能为保留参考图橙红而绕开 ColorScheme，也不能用普通强调色掩盖真实错误。页面、弹窗、导航和 reading 组件不得各自定义一套原始色值。

波形采用当前主题中最亮且满足对比度的前景角色，与主控制的强调角色分开。只对波形绘制结果施加左端透明、中部不透明、右端透明的 alpha 渐变；不渐隐主按钮、错误文字或整个容器。暂停时可降低整体强调，但不换成随机色或生成假振幅。

### 2. 布局优先使用 Flutter Material 组件

录制页顶部为横向宽胶囊，内含真实波形和右侧圆形主录音控制；中央是大字号内容区域；底部是固定顺序的列表、录音、设置三项胶囊导航。间距、安全区、文字换行和容器布局响应可用宽高与字体缩放，不按截图固定像素裁切。

按钮、导航项、对话框、状态提示和状态层优先复用 Flutter Material 组件及其主题能力，保证焦点、禁用、悬停、按压和语义行为一致。自绘仅限真实波形或标准组件无法表达的必要状态形状；不得为复刻外观重写标准按钮、导航或反馈体系。参考图附属右侧图标属于状态示意；已有录音主控制仍是唯一对应录音动作的按钮，不额外增加可点击装饰图标或虚构入口。

中央区域当前展示“仅录音”等真实能力、真实状态和必要提示。无 ASR 接入时不展示预写转写、滚动字幕、伪 GAP 或样例语义卡；将来真实内容接入时沿用大字号层级，并遵守既有 reading 证据和锚点规则。

### 3. 反馈立即开始，语义动作仍由业务手势决定

所有可操作组件按下当帧即启动可见的缩放、Material 状态层或必要形状反馈，不等待点击成立、服务响应或状态确认。反馈只描述触碰与处理过程，不能让 UI 提前宣称正在录音、已经暂停或保存完成。

释放成功后连续过渡到新状态；未达触发条件、手指滑出、手势取消、被滚动接管或业务拒绝时，从当前视觉位置平滑回到实际状态。几何与形状优先继承当前位置和速度，颜色、透明度和内容从当前呈现值接续，反向操作不归零、不重播、不跳帧。布局变化、导航指示器、弹窗出现/关闭、提示更新与实际内容变化同样纳入连续反馈；不能只给录音按钮做动画。

通用按压反馈不争抢手势识别权，不额外消费横向拖动、滚动、单击/双击/长按。录音左滑继续使用真实位移门槛，惯性仅用于视觉接续；reading 的手势优先级与用户接管滚动规则保持。导航只改变页面可见性，不能因离页中断业务或重建控制器。

### 4. 视觉状态服从真实录音安全状态

开始前仍明确请求用户确认“仅录音”；取消确认不调用开始。开始、暂停和继续均以 RecordingController/原生确认更新业务状态，等待期间保留可理解的忙碌反馈，避免重复提交。

振幅来自实际 PCM 的带单调时间戳样本，最新右进、历史左移；录制静音时按真实时间推进，暂停或保存保护时冻结，空闲时不展示旧会话残留。渐隐与绘制平滑不能修改采样时间或伪造音频活动。

录音或暂停时实际左滑达阈值并释放才请求安全结束，速度不能替代位移。未达阈值从当前状态回弹；空闲滑动不创建会话。成功封存后才建立新空闲会话并定位中间页，不自动录音。封存失败保留旧会话、音频文件及诊断证据，显示具体失败，不以过渡动画清空错误或创建替代会话。

### 5. 三页是真实导航，能力状态诚实展示

采用 IndexedStack 或等效持有页面状态的外壳，初始定位中间录音页。列表/录音/设置三个导航项可真正切换对应页面，选中态、可访问标签与内容保持一致；页面实例与 RecordingController 不因选中项改变而反复创建销毁。

历史后端未接入时展示“历史记录尚未接入”等能力说明，不能以“暂无录音”暗示已查询到空结果，也不能用当前会话拼装虚假历史。设置页只提供真实可用的说明或操作，未接入的配置标明尚不可用及原因，不显示能切换却不保存的开关，也不允许无效按钮制造成功反馈。真实空数据、加载失败与未接入状态需要分别表达。

本切片完成只说明真实三页导航与能力边界可用，不等同于旧 TASK-04 §4.7/§4.8 的完整历史和设置验收。既有 `ReaderContext` 若已接入，同会话切页保持，换会话或进程重启清除临时上下文；不得借页面保留持久化跨会话手动锁定。

### 6. 全项目规范覆盖 reading 的将来验收

`app_shell/lib/ui/reading/` 中的 transcript_reader、segment_view、spring_fold、segment_menu、segment_edit_dialog 等既有组件属于 Material 3 全项目规范的约束范围。将来接入或修改时，需要逐项验证语义颜色、Material 菜单/对话框、状态层、按压与取消反馈、形状/颜色/内容/布局过渡、可访问性和减少动态效果。

此约束不改变既有跟随底部/自由阅读、方向性折叠、阅读锚点、单击/双击/长按竞争、GAP 展示与证据不变性。当前未接入录制页的 reading 组件只登记后续实施验收范围，不作为本轮已迁移或已完成页面列入结果。

### 7. 可访问性与减少动态效果

触控目标至少保持 Material 推荐的 48dp，视觉缩放不缩小命中区域；所有可操作项保留文字或可访问标签、选中/忙碌/禁用语义与键盘焦点。装饰性状态图标不独立进入按钮焦点序列，重要状态通过合适语义传达。主要文字与背景达到至少 4.5:1 对比度，大字号文字和必要非文字界面信息达到至少 3:1；波形两端装饰性渐隐不替代可读状态信息。

系统减少动态效果是连续动画要求的明确例外：取消非必要位移、弹簧过冲和持续装饰运动，使用即时或简短状态反馈；操作、取消、左滑门槛与实际业务状态不变。文字缩放与小屏下不能裁切主控制、错误提示或底部导航，也不能靠禁止字体缩放维持截图布局。

## Risks / Trade-offs

- Material ColorScheme 不保证截图的深蓝灰和橙红色相。验收以语义角色、明暗层级与对比度为准，不以截图 RGB 为准；系统壁纸取色不作为本次通过条件。
- 通用动画包装可能吞掉业务拖动或重建语义节点。优先 Material 内建反馈，必要补充必须覆盖取消、反向与手势竞争。
- 仅有页面外壳容易被误解为完整功能。显式能力文案与任务边界必须随界面交付，不能用演示数据掩盖未接入状态。
- 当前无 Android 连接，桌面截图、widget 或历史设备证据不能证明本次真机触控、TalkBack 和采集链路通过。

## Migration Plan

1. 先确立主题、Material 组件主题、语义色与现有动效 token 的统一入口，保持原生与数据契约不变。
2. 将现有录制页接入上述布局、最亮前景渐隐波形及按压/取消反馈；真实波形和安全手势继续由原有状态驱动。
3. 接入保留状态的最小三页导航，历史与设置按真实接入程度展示能力说明。
4. 实现已完成本机集成；主 agent 录音目录测试最终 40 项通过、Web 构建通过，首轮 analyzer 无问题，Edge 完成两种视口三页导航与布局验证。Android 离线构建因依赖缓存缺口失败，严格结构校验未运行；对应复合验收保持未勾选，详见 [Evidence](tasks.md#evidence)。
5. 未下载或安装依赖，不改旧任务和主规格；TASK-01、TASK-04 与原变更的未通过门禁继续保持原状态。reading 组件的逐项迁移与验收留在其实际接入范围完成，不预先宣称成功。

## Verification Plan

- 主题：检查颜色来源为 Material ColorScheme 生成方案与组件语义角色，ColorScheme.fromSeed 可满足要求；未硬编码图片 RGB 或品牌调色板，覆盖 Material 状态层与组件主题，不强求系统壁纸取色。
- 交互：覆盖按下即反馈、成立、滑出、取消、业务拒绝、反向和连续点击；验证颜色、形状、内容和布局连续，不抢左滑或滚动。
- 录音：覆盖仅录音确认取消、原生确认、暂停/继续、空闲/冻结波形、位移阈值、封存成功/失败和证据保留。
- 导航：切页保留状态、录音不中断；能力未接入时说明准确、无假历史/假设置/假转写。
- 可访问性与视觉：Material 主题变化、屏幕宽高、字体缩放、TalkBack、减少动态效果、亮前景波形双端渐隐及触控目标。
- 结果：主 agent 的实际命令、退出码、首轮失败及修复、浏览器范围与待验收项已记录在 [Evidence](tasks.md#evidence)。截图仅存 /tmp、未入库；Android 构建失败无成功 APK，当前无 Android 连接，OpenSpec CLI 实际入口缺失且未重跑已知失败脚本。定向测试与浏览器视觉结果不替代完整项目门禁或原生采集证据。
